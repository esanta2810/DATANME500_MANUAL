# Manual interactivo DATAN ME500 / SINUMERIK 808D

Manual educativo estático para abrir en navegador o publicar en GitHub Pages.

## Abrir localmente

- Opción sencilla: abre `index.html` en un navegador moderno.
- Opción recomendada: ejecuta `python app.py` y visita `http://127.0.0.1:8000`.

## Publicar en GitHub Pages

1. Descomprime el ZIP.
2. Sube el contenido completo del ZIP a la raíz del repositorio. Conserva las carpetas `css`, `js` e `img`.
3. En Settings → Pages selecciona `Deploy from a branch`, rama `main` y carpeta `/(root)`.
4. Espera a que termine el despliegue de Pages.

`app.py` sirve el manual localmente; GitHub Pages publica los archivos estáticos y no ejecuta Python.

## Mejoras de esta versión

- Fotos de referencia para mesa, cambiador de herramienta, fresas y paneles de control.
- Secuencia visual de puesta en marcha y apagado.
- Guía interactiva paso a paso para introducir y guardar un programa.
- Guía interactiva para cargar, simular, usar Single Block, Dry Run y Cycle Start.
- Práctica de maquinado con resaltado de bloques G-code y movimiento didáctico línea por línea.
- Sección 9 de seguridad y sección 10 de diagnóstico.

## Importante

Las pantallas de referencia generadas o ilustrativas no garantizan que las softkeys o la distribución coincidan exactamente con toda versión del SINUMERIK 808D. El simulador es educativo y no controla una máquina real. Para operar la DATAN ME500, sigue el manual del fabricante, el procedimiento de tu laboratorio y la supervisión del instructor.
